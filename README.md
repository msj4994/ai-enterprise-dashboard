# ai-enterprise-dashboard
AI-powered enterprise analytics dashboard built with Angular 18, Node.js, and modern frontend architecture.

## Overview

Dashboard is a modern enterprise-style analytics platform designed to showcase scalable frontend architecture, reusable Angular components, AI-ready integrations, and responsive dashboard experiences.

This project was built as a portfolio-ready application for remote frontend/full-stack engineering opportunities.

---

# Features

- Angular 18 architecture
- Reusable dashboard components
- Responsive enterprise UI
- AI-inspired analytics layout
- Modern glassmorphism theme
- Scalable project structure
- Node.js backend ready
- API integration support
- Mobile responsive design

---

